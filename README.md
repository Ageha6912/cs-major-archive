# CS MAJOR ARCHIVE · 历代 Major 冠军档案

一个展示 CS:GO / CS2 全部 24 届 Major（2013 DreamHack Winter — 2026 IEM Cologne）的档案型首页。

## 功能

- **冠军殿堂**：24 届冠军卡片横向长廊，标注冠亚军、比分、MVP、赛事奖金与夺冠次数，可按 CS:GO / CS2 时代筛选。
- **编年史**：按时间轴展示每一届的决赛地图比分、场馆、奖金与名场面视频，默认折叠为前 6 届，可一键展开全部。
- **HLTV TOP20**：2013—2025 十三届年度最佳选手榜单，含名次、国旗、选手与当年所效力战队。
- **名人堂**：把十三年 TOP20 名额叠加成常青树榜——按上榜次数 / 前十次数 / 登顶次数 / 最佳名次排序，点击选手可展开其逐年排名，支持搜索。
- **详情页**：点击任意一届进入全屏详情——淘汰赛四强/八强、全员参赛名单、冠军与亚军阵容、当年 TOP20 中的冠军成员、决赛视频（点击播放）。
- 首页 Hero 右侧含“冠军俱乐部（多冠战队）”与“历届冠军速览”面板；页面右下角有回到顶部按钮。

## 设计

- 暗色年鉴风格：炭黑底 + 香槟金（CS:GO 时代）/ 电光青（CS2 时代）双色体系，Bebas Neue 大标题与 Oswald 标题字（已本地打包，离线可用）。
- 战队徽章：16 支冠军战队使用真实 Logo（本地 `public/logos/`，来源 Wikimedia / Liquipedia），其余战队自动回退为六边形字母徽章。
- 动效克制：滚动渐显、数字滚动、冠军卡悬停、顶部滚动进度条与标题走马灯；适配 `prefers-reduced-motion`。
- 移动端：冠军长廊横向滑动、时间轴单列、详情页纵向堆叠。

## 数据

- `data/majors.json` — 24 届赛事元数据（场馆、奖金、冠亚军阵容、四强、八强、全员参赛名单）。
- `data/final_maps.json` — 每届决赛地图与比分。
- `data/top20.json` — HLTV 年度 TOP20（2013—2025）。
- `data/videos.json` — 每届名场面视频（YouTube，已在详情页内嵌播放）。

数据整理自 Wikipedia 与 HLTV，视频版权归原作者所有。解析与校验脚本位于 `scripts/`。
